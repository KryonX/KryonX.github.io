🍪 Opdracht 1 – Cookies

Wat is een cookie?

Een cookie is een stukje data dat opgeslagen wordt in de browser van de gebruiker. PHP kan cookies lezen en instellen. Ze blijven bewaard ook als de gebruiker de pagina herlaadt of de browser sluit.

Cookie instellen

setcookie('naam_van_cookie', 'waarde', time() + 3600);
//                                              ^^^^ vervaltijd = 1 uur in seconden

Cookie uitlezen

if (isset($_COOKIE['naam_van_cookie'])) {
    $waarde = $_COOKIE['naam_van_cookie'];
    echo "Cookie gevonden: $waarde";
}

Cookie direct beschikbaar maken na instellen

setcookie('gebruiker', 'Ahmed', time() + 3600);
$_COOKIE['gebruiker'] = 'Ahmed'; // Nodig zodat cookie direct beschikbaar is op dezelfde pagina

⚠️ Let op: volgorde

setcookie() moet vóór alle HTML-output worden aangeroepen. Dus ook vóór <!DOCTYPE html> of echo-statements.

FunctieWat doet het
setcookie('naam', 'waarde', vervaltijd)Stelt een cookie in
$_COOKIE['naam']Leest de cookiewaarde
isset($_COOKIE['naam'])Controleert of de cookie bestaat
time() + 3600Vervaltijd: nu + 1 uur

🔌 Opdracht 2 – PDO Databaseverbinding

Wat is PDO?

PDO (PHP Data Objects) is de standaard manier in PHP om met een database te praten. Het werkt met meerdere databases (MySQL, PostgreSQL, etc.) en ondersteunt prepared statements voor veiligheid.

Verbinding opzetten

$pdo = new PDO("mysql:host=localhost;dbname=webshop_p04;charset=utf8", "root", "");
$pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);

Altijd in een try-catch!

try {
    $pdo = new PDO("mysql:host=localhost;dbname=webshop_p04;charset=utf8", "root", "");
    $pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
    echo "Verbinding gelukt!";
} catch (PDOException $e) {
    echo "Fout: " . $e->getMessage(); // Toont de foutmelding als verbinding mislukt
}
OnderdeelUitleg
mysql:host=localhostHet adres van de databaseserver
dbname=webshop_p04De naam van de database
charset=utf8Tekencoding (altijd meegeven!)
ERRMODE_EXCEPTIONGooit een fout als iets misgaat
PDOExceptionHet type fout dat PDO gooit

📋 Opdracht 3 – Producten uitlezen (READ)

Alle rijen ophalen

$stmt = $pdo->query("SELECT * FROM producten");
$producten = $stmt->fetchAll(PDO::FETCH_ASSOC);
// fetchAll() geeft een array van alle rijen terug als associatieve arrays

Weergeven in HTML-tabel

    </thead>
    <tbody>
        <?php foreach ($producten as $product): ?>
        <tr>
            <td><?= htmlspecialchars($product['id']) ?></td>
            <td><?= htmlspecialchars($product['naam']) ?></td>
            <td>€<?= htmlspecialchars($product['prijs']) ?></td>
        </tr>

ℹ️ FETCH_ASSOC

PDO::FETCH_ASSOC geeft de data terug als een array waar je de kolomnaam als sleutel gebruikt: $product['naam']. Zonder dit krijg je ook genummerde sleutels: $product[1].

🛡️ Opdracht 4 – Prepared Statements (INSERT)

🚨 Waarom prepared statements?

Zonder prepared statements kan een gebruiker kwaadaardige SQL invoeren via een formulier. Dit heet SQL-injectie.

Gevaarlijk voorbeeld: stel iemand vult in als naam: '; DROP TABLE producten; --

Met prepared statements worden invoerwaarden nooit direct in de SQL-query gezet — ze worden apart verstuurd en de database behandelt ze altijd als data, nooit als SQL-code.

INSERT met prepared statement

// Stap 1: bereid de query voor met :placeholders
$stmt = $pdo->prepare("INSERT INTO producten (naam, prijs, voorraad) VALUES (:naam, :prijs, :voorraad)");

// Stap 2: koppel waarden aan de placeholders (bindParam)
$stmt->bindParam(':naam',     $naam);
$stmt->bindParam(':prijs',    $prijs);
$stmt->bindParam(':voorraad', $voorraad);

// Stap 3: voer de query uit
$stmt->execute();

Kortere variant met execute array

$stmt = $pdo->prepare("INSERT INTO producten (naam, prijs, voorraad) VALUES (:naam, :prijs, :voorraad)");
$stmt->execute([
    ':naam'     => $_POST['naam'],
    ':prijs'    => $_POST['prijs'],
    ':voorraad' => $_POST['voorraad']
]);

Formulier verwerken

if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    // Formulier is verstuurd, verwerk de data
    $naam = $_POST['naam'];
    // ... rest van de code
}
MethodeWanneer gebruiken
bindParam()Koppelt een PHP-variabele aan een placeholder
execute([...])Voert query uit, kan direct waarden meegeven
$_SERVER['REQUEST_METHOD']Controleren of formulier via POST verstuurd is

⚙️ Opdracht 5 – Volledige CRUD

CRUD = 4 basisoperaties

LetterBetekenisSQLHTTP
CCreate – aanmakenINSERTPOST
RRead – lezenSELECTGET
UUpdate – wijzigenUPDATEPOST
DDelete – verwijderenDELETEGET (via link)

SELECT – alle producten ophalen

$producten = $pdo->query("SELECT * FROM producten")->fetchAll(PDO::FETCH_ASSOC);

INSERT – nieuw product toevoegen

$stmt = $pdo->prepare("INSERT INTO producten (naam, prijs, voorraad) VALUES (:naam, :prijs, :voorraad)");
$stmt->execute([':naam' => $naam, ':prijs' => $prijs, ':voorraad' => $voorraad]);

UPDATE – product wijzigen

$stmt = $pdo->prepare("UPDATE producten SET naam=:naam, prijs=:prijs, voorraad=:voorraad WHERE id=:id");
$stmt->execute([':naam' => $naam, ':prijs' => $prijs, ':voorraad' => $voorraad, ':id' => $id]);
// ⚠️ Altijd WHERE id=:id meegeven anders worden ALLE rijen gewijzigd!

DELETE – product verwijderen

$stmt = $pdo->prepare("DELETE FROM producten WHERE id = :id");
$stmt->execute([':id' => $_GET['verwijder']]);
// ⚠️ Altijd WHERE meegeven anders worden ALLE rijen verwijderd!

Actie detecteren via $_POST of $_GET

// Via hidden input in formulier
<input type="hidden" name="actie" value="toevoegen">

// In PHP controleer je dan:
if (isset($_POST['actie']) && $_POST['actie'] === 'toevoegen') {
    // voer INSERT uit
}

// Verwijderen via link:
<a href="?verwijder=5">Verwijderen</a>
// In PHP:
if (isset($_GET['verwijder'])) { ... }

Wijzigknop: id meesturen via GET

<a href="?wijzig=<?= $product['id'] ?>">Wijzigen</a>

// In PHP haal je dan één product op:
if (isset($_GET['wijzig'])) {
    $stmt = $pdo->prepare("SELECT * FROM producten WHERE id = :id");
    $stmt->execute([':id' => $_GET['wijzig']]);
    $wijzig = $stmt->fetch(PDO::FETCH_ASSOC);
}

🔗 Opdracht 6 – Master-Detail Patroon

Wat is master-detail?

Een overzichtspagina (master) toont alle items. Als je op een item klikt ga je naar een detailpagina die één item uitgebreid toont. Het id van het item wordt via de URL meegegeven.

producten.php – overzicht (master)

<?php
$producten = $pdo->query("SELECT * FROM producten")->fetchAll(PDO::FETCH_ASSOC);
?>
<?php foreach ($producten as $p): ?>
    <tr>
        <td><?= htmlspecialchars($p['naam']) ?></td>
        <!-- Stuur id mee in de URL -->
        <td><a href="product_detail.php?id=<?= $p['id'] ?>">Bekijk details</a></td>
    </tr>
<?php endforeach; ?>

product_detail.php – detailpagina

<?php
// Haal id op uit de URL
$id = $_GET['id'];

// Gebruik prepared statement! (id komt uit de URL = gebruikersinvoer = gevaarlijk)
$stmt = $pdo->prepare("SELECT * FROM producten WHERE id = :id");
$stmt->execute([':id' => $id]);
$product = $stmt->fetch(PDO::FETCH_ASSOC);

if (!$product) {
    die("Product niet gevonden.");
}
?>

🚨 Waarom prepared statement op de detailpagina?

Het id in de URL (?id=1) kan door een gebruiker aangepast worden naar kwaadaardige SQL. Gebruik daarom altijd een prepared statement, ook als het maar één waarde is!

🔒 Veiligheid – XSS & SQL-injectie

XSS – Cross-Site Scripting

Als je gebruikersinvoer direct echo'd, kan iemand JavaScript-code in je pagina injecteren:

// GEVAARLIJK:
echo $_POST['naam']; // Stel iemand vult in: <script>alert('gehackt!')</script>

// VEILIG:
echo htmlspecialchars($_POST['naam']); // Zet < en > om naar &lt; en &gt;

Regel: gebruik altijd htmlspecialchars() als je data uit de database of formulier weergeeft in HTML.

SQL-injectie

Als je waarden direct in je SQL-query plakt:

// GEVAARLIJK:
$naam = $_POST['naam'];
$pdo->query("SELECT * FROM producten WHERE naam = '$naam'");
// Iemand vult in: ' OR '1'='1  → alle rijen worden teruggegeven!

// VEILIG: prepared statement
$stmt = $pdo->prepare("SELECT * FROM producten WHERE naam = :naam");
$stmt->execute([':naam' => $naam]);

SQL-injectieKwaadaardige SQL via invoerPrepared statements

Databaseverbinding (kopieer dit altijd)

try {
    $pdo = new PDO("mysql:host=localhost;dbname=JOUW_DB;charset=utf8", "root", "");
    $pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);

    die("Verbinding mislukt: " . $e->getMessage());
}

Alle CRUD queries

// SELECT (alle rijen)
$rijen = $pdo->query("SELECT * FROM tabel")->fetchAll(PDO::FETCH_ASSOC);

// SELECT (één rij op id)
$stmt = $pdo->prepare("SELECT * FROM tabel WHERE id = :id");
$stmt->execute([':id' => $id]);
$rij = $stmt->fetch(PDO::FETCH_ASSOC);

// INSERT
$stmt = $pdo->prepare("INSERT INTO tabel (kolom1, kolom2) VALUES (:v1, :v2)");
$stmt->execute([':v1' => $v1, ':v2' => $v2]);

// UPDATE
$stmt = $pdo->prepare("UPDATE tabel SET kolom1=:v1, kolom2=:v2 WHERE id=:id");
$stmt->execute([':v1' => $v1, ':v2' => $v2, ':id' => $id]);

// DELETE
$stmt = $pdo->prepare("DELETE FROM tabel WHERE id = :id");
$stmt->execute([':id' => $id]);

Cookies

setcookie('sleutel', 'waarde', time() + 3600); // Instellen (1 uur geldig)
$_COOKIE['sleutel'] = 'waarde';               // Direct beschikbaar maken
$waarde = $_COOKIE['sleutel'];                 // Uitlezen
isset($_COOKIE['sleutel'])                     // Bestaan controleren

Veilig weergeven

echo htmlspecialchars($variabele); // Altijd gebruiken bij output van user/db data

Formulier verwerken

if ($_SERVER['REQUEST_METHOD'] === 'POST') { /* formulier verstuurd */ }
if (isset($_POST['veld']))  { $waarde = $_POST['veld'];  }
if (isset($_GET['param']))  { $waarde = $_GET['param'];  }
