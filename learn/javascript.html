JavaScript

De taal van het web — van DOM-manipulatie tot fetch requests.

Variabelen

Gebruik const voor vaste waarden en let als de waarde verandert. Vermijd var.

const naam = "Bart";
let score = 0;
score++;

Functies & Arrow functions

// Klassiek
function begroet(naam) {
  return `Hallo, ${naam}!`;
}

// Arrow function
const begroet = (naam) => `Hallo, ${naam}!`;

DOM manipulatie

// Element selecteren en aanpassen
const btn = document.getElementById("mijnKnop");
btn.addEventListener("click", () => {
  btn.textContent = "Geklikt!";
  btn.style.background = "#a78bfa";
});

Fetch API

async function getData() {
  const res = await fetch("https://api.example.com/data");
  const data = await res.json();
  console.log(data);
}
