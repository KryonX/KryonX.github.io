PHP

Server-side scripting for the web — van basis tot database.

Wat is PHP?

PHP (Hypertext Preprocessor) is een server-side scripttaal die draait op de webserver voordat de pagina naar de browser wordt gestuurd. Het is ideaal voor dynamische websites en werkt goed samen met MySQL.

Basis syntax

PHP-code staat altijd tussen <?php en ?> tags.

// Variabelen beginnen altijd met $
$naam = "Bart";
$leeftijd = 21;

// Iets uitprinten
echo "Hallo, " . $naam . "!";

// Array
$kleuren = ["rood", "blauw", "groen"];
echo $kleuren[0]; // rood

PDO Database connectie

Voor een veilige connectie met MySQL gebruik je PDO met prepared statements.

$pdo = new PDO(
  'mysql:host=localhost;dbname=mydb;charset=utf8',
  'username',
  'password'
);
$pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);

// Prepared statement (veilig tegen SQL injection)
$stmt = $pdo->prepare("SELECT * FROM users WHERE id = :id");
$stmt->execute(['id' => $id]);
$user = $stmt->fetch(PDO::FETCH_ASSOC);
